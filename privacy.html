시행일: 2026년 11월 17일

1. 적용 대상

본 방침은 Pickgear 채널 운영자가 사용하는 내부용 도구 "Pickgear Uploader"(이하 "앱")에 적용됩니다. 앱은 운영자 본인의 YouTube 채널에 영상을 업로드하는 용도로만 사용되며, 일반 사용자에게 제공되지 않습니다.

2. 수집·이용하는 정보

앱은 Google OAuth를 통해 운영자 본인의 YouTube 계정에 대한 접근 권한(youtube 범위)만 요청합니다. 이 권한은 영상 업로드, 제목·설명·태그 입력, 공개 예약, 유료 프로모션 표시 설정에만 사용됩니다. 그 밖의 개인정보는 수집하지 않습니다.

3. 보관 및 제3자 제공

발급된 인증 토큰은 운영자의 작업 환경에만 저장되며 제3자에게 제공·판매·공유하지 않습니다. 운영자는 언제든지 Google 계정 권한 설정에서 앱의 접근 권한을 철회할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
